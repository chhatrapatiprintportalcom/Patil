CHHATRAPATI RETAILER PORTAL — OFFLINE PERSONAL VERSION

कसे सुरू करायचे:
1. ZIP extract करा.
2. index.html वर double-click करा किंवा Chrome/Edge मध्ये उघडा.
3. Internet/API शिवाय local demo वापरता येईल.

उपलब्ध:
- Dashboard
- Service request forms (PAN Search, Farmer PDF/ID, Voter ID, RC, Aadhaar-related request, Maha Sarathi, Ayushman request)
- Local users/retailer list
- Editable service rates
- Manual wallet ledger (credit/debit)
- Transaction history + CSV export
- JSON backup/import
- Browser localStorage मध्ये local data

महत्त्वाच्या मर्यादा:
- हा personal/offline prototype आहे; live government lookup नाही.
- API/provider शिवाय Aadhaar/PAN/Voter/RC ची खरी माहिती किंवा अधिकृत PDF मिळू शकत नाही.
- Users/retailers फक्त local list आहेत; खरे login/password, multi-device access किंवा server database नाही.
- Wallet entries manual आहेत; payment gateway/UPI reconciliation नाही.
- Demo balance ₹99,99,99,999 फक्त display साठी आहे, तो real money किंवा spendable wallet balance नाही.
- Full Aadhaar/PAN numbers किंवा sensitive documents इथे सेव्ह करू नका.
- Browser local storage साफ केल्यास data जाऊ शकतो; वेळोवेळी JSON backup घ्या.

Production version साठी secure backend/database, authentication, hosting आणि संबंधित सेवांसाठी authorized access आवश्यक असेल.
